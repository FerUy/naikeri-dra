= Introduction

{this-platform} {this-application} is a Diameter Routing Agent built on the {this-platform} Signaling Gateway and jDiameter.
It routes Diameter requests between peers by configurable rules, over SCTP with multi-homing.

This guide covers installing {this-platform} {this-application}, configuring the essentials, running it and removing it.
Its routing rules and Diameter configuration are described in the {this-platform} {this-application} Admin Guide.
