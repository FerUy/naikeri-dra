[[_prerequisites]]
= Pre-Requisites

.Installation Pre-Requisites
[cols="1,3", frame="all", options="header"]
|===
| Component | Requirement
| Operating system | Linux, with SCTP support in the kernel. {this-platform} {this-application} is tested on Ubuntu LTS.
| Java | A Java 11 runtime (JRE or JDK) on the `PATH`. The appendix of this guide describes installing one.
| SCTP library | The `lksctp-tools` package, which the Java runtime needs to open SCTP associations.
| Memory | `bin/start.sh` starts the JVM with a 1 GB heap (`-Xms1g -Xmx1g`): allow for it, plus the operating system.
| Network | The SCTP port of the local Diameter peer (3868 in the configuration shipped) open between {this-application} and its peers, on every address used for multi-homing.
| PostgreSQL | Optional: only needed when realm and application data are kept in a database rather than in `diameter-server.xml`.
|===
