[[_installation]]
= Installation

{this-platform} {this-application} is distributed as a single zip, `Naikeri-DRA-<version>.zip`.
Unpack it wherever it should live, for example under `/opt/naikeri/dra`:

[source,bash]
----
mkdir -p /opt/naikeri/dra
cd /opt/naikeri/dra
unzip Naikeri-DRA-<version>.zip
----

There is no installer, and running it needs no root access. The installation directory holds:

[cols="1,3", frame="all", options="header"]
|===
| Directory | Contents
| `bin/` | The {this-application} jar, its dependencies in `libs/`, the management jar, `start.sh` and `dra-cli.sh`
| `conf/` | The configuration: `naikeri-signaling-gateway.xml`, `diameter-server.xml`, `dictionary.xml`, `log4j2.xml`, `application.yaml` and `db.sql`
| `logs/` | Where {this-application} writes its logs
|===
